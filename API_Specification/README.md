# CAB System API Specification

This folder contains the CAB System Swagger/OpenAPI documentation.

- `openapi.yaml` — main Swagger/OpenAPI document.
- Each REST API operation has its own YAML file.
- `x-br` and `x-fr` mappings are preserved for B7 traceability.

API files use clear English names, for example `create-ride.yaml`, `get-ride.yaml`, and `dispatch-driver.yaml`.
